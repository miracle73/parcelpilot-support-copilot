# Requirements audit

- Natural-language chat: customer and internal roles.
- Supplied data only: six PDFs plus workbook, parsed dynamically.
- Reliability: authority, deprecated exclusion, agreement override, confidence, conflicts, escalation.
- Privacy: account filtering inside document/order/ticket tools; non-enumerable denial.
- Agent tools: retrieval, structured lookup/calculation, confirmed action, and issue detection.
- Confirmation: separate prepare/confirm endpoints; prepare performs no mutation.
- Multi-step: order → account → agreement → SOP → calculation → action proposal.
- Interface: visible tool trace, evidence, confidence, and action preview.
- Proactive detection: P1, SLA breach, and known-issue radar.
- Submission notes: architecture, product, priorities, omissions, metric, AI disclosure.
- Candidate-owned external items: hosted URL and recorded video.
